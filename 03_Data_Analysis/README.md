# Data Analysis and Insights

## Overview

This folder contains the simulated dataset and data analysis deliverables developed for the Palm Haven Hotel & Resort — Guest Retention Recovery project.

The analysis focuses on examining guest behaviour, booking patterns, customer satisfaction, repeat bookings, corporate accounts, revenue performance, and other relevant business indicators.

## Deliverables

### 1. Simulated Dataset
A structured hospitality dataset containing simulated guest stay, booking, property, revenue, and service-related records.

### 2. Microsoft Excel Analysis
Excel was used for data exploration, calculations, summary analysis, Pivot Tables, and dashboard development.

### 3. Power BI Dashboard
Power BI was used to present key performance indicators and business insights through interactive visualisations.

## Analytical Focus

- Guest retention and repeat bookings.
- Customer satisfaction.
- Revenue performance.
- Booking channels.
- Guest demographics.
- Corporate customer performance.
- Maintenance complaints and service experience.

## Purpose

The analysis provides data-supported insights to help explain the business challenges and inform recommendations for improving guest retention.

**Data Disclaimer:** All records and figures are simulated and do not represent actual hotel operations or customers.
