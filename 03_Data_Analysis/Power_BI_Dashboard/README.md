# Power BI Dashboard

## Overview

This folder contains the Power BI dashboard developed for the Palm Haven Hotel & Resort — Guest Retention Recovery capstone project.

The dashboard presents key business performance indicators and visual insights derived from the simulated hospitality dataset.

## Dashboard Objectives

- Monitor guest retention and repeat booking performance.
- Examine revenue contribution across relevant categories.
- Analyse guest demographics and booking patterns.
- Evaluate customer satisfaction.
- Identify operational and service-related trends.
- Support business decision-making through data visualisation.

## Tools Used

- Microsoft Power BI Desktop.
- Power Query for data preparation.
- Data modelling and DAX measures.
- Interactive charts, tables, filters, and KPI visualisations.

## Deliverable

The Power BI report file will be provided in this folder after its final review and preparation for public sharing.

**Note:** The dashboard uses simulated project data and is intended for educational and portfolio demonstration purposes.
