# Dashboard Screenshots

## Overview

This folder contains selected screenshots from the Excel and Power BI analysis developed for the Palm Haven Hotel & Resort — Guest Retention Recovery project.

The screenshots provide a visual summary of the analytical outputs and key business insights.

## Contents

### 1. Dashboard Overview
A visual presentation of the project's main dashboard and selected performance indicators.

### 2. Survey Analysis
A visual summary of the survey-related analysis and findings included in the project.

## Purpose

The screenshots allow recruiters, reviewers, and other visitors to quickly understand the project's data visualisation outputs without first opening the original Excel or Power BI files.

**Note:** All information presented in these screenshots is simulated for educational and portfolio demonstration purposes.
