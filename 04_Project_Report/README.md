# Final Capstone Project Report

## Overview

This folder contains the consolidated project report for Palm Haven Hotel & Resort — Guest Retention Recovery.

The report brings together the business problem, project background, analysis, findings, proposed improvements, recommendations, and expected business outcomes.

## Report Coverage

- Project background and organisational overview.
- Business problem identification.
- Project objectives and scope.
- Stakeholder and business analysis.
- Findings from the simulated data.
- Business requirements and process improvement.
- Proposed solution and recommendations.
- Business case and expected benefits.
- Conclusion and lessons learned.

## Purpose

The report provides an overall account of the Business Analysis capstone project and demonstrates the application of structured analysis and problem-solving techniques.
